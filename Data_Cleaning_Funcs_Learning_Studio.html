LESSON 01

Handling missing values fillna()

Replace missing values with a sensible value.

The idea

Think of NaN as an empty seat. fillna() decides what should go into that seat instead of leaving it empty.

From your notebook

The notebook fills Age with the mean age and Score with 0.

Remember

Use a value that makes sense for the column. A mean can be useful for numeric measurements; zero is appropriate only when zero truly means something in that context.

Start with this pattern
df["Age"] = df["Age"].fillna(df["Age"].mean())
df["Age"] = df["Age"].fillna(df["Age"].mean())

LESSON 02

Forward fill ffill()

Carry the last known value downward.

The idea

Imagine reading a list top-to-bottom: when a value is missing, ffill() looks backward for the most recent known value.

From your notebook

The notebook sorts the data first, then forward-fills missing Age and Score.

Remember

Order matters. Forward fill follows the current row order, so sorting can change which value gets propagated.

Start with this pattern
df["Score"] = df["Score"].ffill()
df["Score"] = df["Score"].ffill()
See the exact notebook result

Original code

LESSON 03

Backward fill bfill()

Use the next known value to fill a gap.

The idea

This is the mirror image of ffill(): when a value is missing, look forward to the next available value.

From your notebook

The notebook sorts descending and then applies bfill() to Age and Score.

Remember

Backward fill is also order-dependent, so always think about the row order before filling.

Start with this pattern
df["Score"] = df["Score"].bfill()
df["Score"] = df["Score"].bfill()
See the exact notebook result

Remove missing rows or columns dropna()

Delete data containing NaN according to a rule.

The idea

From your notebook

Remember

Always be explicit about the rule you want. Dropping data can be much more destructive than filling it.

Start with this pattern

LESSON 08

Keep values inside a range clip()

Push values below/above limits back to the boundaries.

The idea

clip() is like putting a guardrail around a number: below the lower bound becomes the lower bound; above the upper bound becomes the upper bound.

From your notebook

The notebook keeps Age between 20–40 and Score between 60–100 after filling NaN values.

Remember

Clipping changes outliers to the boundary; it does not remove the row.

Start with this pattern
df["Age"] = df["Age"].clip(lower=20, upper=40)
df["Age"] = df["Age"].clip(lower=20, upper=40)

# Create a new column 'Age_Group' based on 'Age'

def get_age_group(age):
    if pd.isna(age):
        return 'Unknown'
    elif age < 30:
        return 'Young'
    else:
        return 'Adult'
