# Tips

1. **Exam code:** Do not write `__new__`, `__main__`, or extra runner/testing code in the exam. Submit only the required class and its required functions/methods.

2. **Set up first:** For both questions, first create the class and every required function/method with `pass` inside. This makes sure the complete structure is ready before you start implementing.

3. **Implement and test:** Then fill in the functions one by one. While you are still in the exam, run tests, validate outputs, use the terminal, and check edge cases.

4. **Do not submit early:** Keep testing and fixing until both questions are finished and validated. Do not submit after only one question works.

5. **Submit both:** Before leaving the exam, make sure **both questions are completed and submitted**. Do not forget the second question.

6. **Preserve the interface:** Keep the exact class names, function/method names, parameters, and expected return values from the question.
